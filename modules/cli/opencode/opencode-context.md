# Prompt refinement

Before implementing a task:

1. Analyze the user's request for ambiguities,
   missing requirements, and potential improvements.
2. Identify important decisions that could affect
   the implementation.
3. Use the question tool to ask targeted clarifying
   questions when additional information would
   meaningfully improve the result.
4. Prefer multiple-choice questions with recommended
   defaults.
5. Do not ask questions whose answers can be
   determined from the codebase.
6. Once requirements are clear, proceed with
   implementation.

For complex tasks, propose an implementation plan
before making changes.
